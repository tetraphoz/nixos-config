# NixOS configuration docs

This directory documents the flake and the `p52` host. The configuration is
personal and hardware-specific; use the host modules as the source of truth
when details here drift.

## Guides

- [Configuration map](configuration.md) — flake outputs, module responsibilities,
  packages, and hardware-specific overrides.
- [Operating the system](operations.md) — validate, test, rebuild, update,
  roll back, and troubleshoot the main services.

The repository's [README.org](../README.org) has a shorter project overview and
dotfiles notes.
